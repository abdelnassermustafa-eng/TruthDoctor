# TruthDoctor

## Cloud Infrastructure Validation Desktop Application

TruthDoctor is a cross-platform desktop application built with Avalonia UI and .NET that provides engineers with a graphical interface for validating and reviewing cloud infrastructure environments.

The application integrates with TruthApi to authenticate users, retrieve infrastructure validation reports, and present operational data through an intuitive desktop experience.

---

## Overview

TruthDoctor was designed to provide a desktop-based operational interface for cloud and infrastructure engineers.

Using TruthDoctor, engineers can:

* Authenticate securely against TruthApi
* Retrieve infrastructure validation reports
* Review validation results visually
* Monitor operational status
* Analyze infrastructure findings
* Improve cloud operational visibility
